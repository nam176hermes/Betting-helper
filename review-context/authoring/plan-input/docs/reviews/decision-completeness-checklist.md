# Decision-Completeness Checklist

A fresh implementer must not choose:

- the successor source or destination;
- which paths/URNs/registries are rebound;
- when an artifact becomes exact;
- which task owns a required artifact;
- which tests pytest or TypeScript compile;
- which harness executes a crash vector;
- clock failure precedence;
- which cybersecurity attacks are run;
- review workspace, input or output roots;
- review freshness, expiry or aggregation rules;
- internal versus external hash bindings.

Any remaining choice above rejects the plan.
