# One acyclic seal algorithm

For the plan and future runtime pack use the exact algorithm implemented in plan_tools/common.py. File names are NFC UTF-8 relative paths sorted by UTF-8 bytes. A leaf is SHA256(b"HYBRID-DISCOVERY/v6.3.6/GOVERNED-FILE/v1\0" + path_utf8 + b"\0" + raw_file_sha256). Root is SHA256(b"HYBRID-DISCOVERY/v6.3.6/GOVERNED-ROOT/v1\0" + concatenated uint32_be(path_byte_length), path_utf8, leaf_sha256). Both domain suffixes are /v1. Other versions fail.

The governed-root exclusion set is exactly GOVERNED_CONTENT_ROOT.json, SELF_REVIEW_REPORT.md, SELF_REVIEW_REPORT.json, MANIFEST_SHA256.json. The ZIP, sidecar and external attestation are physically outside the root and therefore cannot be excluded by a broad glob. All other files are governed, including this policy and its registry. Internal self-review binds only the governed root, task manifest and earlier evidence. It must not bind final manifest, ZIP, sidecar or attestation identities. Plan self-review cannot claim runtime or independent-review qualification.

Order: validate plan -> freeze governed files -> governed root -> self-review JSON/Markdown -> self-excluding manifest -> deterministic ZIP -> external attestation. Runtime pack order likewise requires REPO0 and candidate receipts before its self-review. Every file is a regular non-symlink single-link file; absolute paths, traversal, non-NFC paths, duplicate names and extra files fail. ZIP uses sorted entries, fixed 1980-01-01 timestamp, UNIX regular 0644 mode, ZIP_STORED, no extra/comment, no directory records. Independent rebuild must be byte-identical.

Attestation schema distinguishes PLAN from RUNTIME_PACK. PLAN binds ZIP, manifest, governed root, self-review hashes and task-manifest hash. RUNTIME_PACK additionally requires REPO0 receipt, baseline commit/tree/file-root and candidate receipt. Attestation stays outside ZIP. The file hash is an integrity binding, not a cryptographic issuer signature or production authorization.
